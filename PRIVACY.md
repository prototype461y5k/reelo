# Privacy Policy — Reelo

Last updated: 2026

Reelo is designed to respect your privacy. In short: the app collects no data about you and sends no personal information to any server.

## Data collected

**No data is collected.** Reelo has no account, login, sign-up or profile. It collects no name, no email, and no usage statistics.

## Analytics and telemetry

Reelo contains **no** analytics, telemetry, crash reporting or advertising trackers. No third-party tracking tools are used.

## Network connections

The app only connects to Vimeo's own domains (`vimeo.com`, `api.vimeo.com`, and the Vimeo CDN hosts that serve the videos) in order to work with the review link you paste. It connects to no other server.

## Where your data lives

- **Downloaded videos** are saved only to the folder you choose, on your own computer.
- **Download history** (used to remember which videos are already downloaded) is kept only on your computer, as a local JSON file under `~/Library/Application Support/boink_archives/`.
- **The session token (JWT)** is held only in memory for the current download session; it is never written to disk permanently.

None of this data ever leaves your computer.

## Third parties

Reelo communicates only with Vimeo in order to download the videos. How Vimeo handles that content is governed by Vimeo's own privacy policy.

## Contact

For questions about this policy, please use the **Issues** section of the project repository.
